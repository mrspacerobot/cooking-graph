## Boundaries for the growth round

A name is added only when it names the same thing. A family is not made an alias
of one move. A method-changing substitute is not entered as a stand-in. A recipe
that does not use the probe's original ingredient is not rewritten to manufacture
an answer. Bakery dishes outside this slice wait. Every new thing and statement
remains drafted and every safety record remains unverified.

Question probes are independent drafts, not authoritative cooking judgments.
For example, consommé needs clarification ingredients, a cream sauce needs
cream, and a pantry for one variation need not fill another. These doubts are
kept for the owner; neither graph nor probe is altered to hide them.
